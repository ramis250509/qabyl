# Что нужно сделать руками, чтобы self-service заработал

Дата: 2026-09-09. Всё, что можно было сделать кодом, — сделано. Здесь только то, что требует
доступа к базе, к кабинету Meta или к настройкам Cloudflare.

Порядок важен: пункты 1–3 обязательны, без них ничего не работает.

---

## 1. Применить миграцию к базе

Файлы:
- `supabase/migrations/20260909090000_self_service_onboarding.sql` → `name: self_service_onboarding`
- `supabase/migrations/20260909100000_wa_health_cron.sql` → `name: wa_health_cron`

Без них:

- регистрация нового владельца **упадёт** на шаге «Расскажите о салоне» (нет функции
  `create_salon_for_owner`);
- кнопка «Проверить подключение» на вкладке WhatsApp **упадёт** (нет колонок состояния);
- журнал подключений будет молча пустым.

Применять через Supabase MCP, передав в `name` ровно `self_service_onboarding` — так
`scripts/check-migrations.mjs` свяжет файл с записью в базе (см. `.claude/skills/new-migration`).

После применения:

```bash
node scripts/check-migrations.mjs < db-migrations.json
```

**Разовая чистка после миграции.** У двух салонов (`Эркеайым`, `Test saloon`) в
`salon_secrets.whatsapp_cloud_app_secret` лежит копия общего секрета платформы — его туда писал
прежний код подключения. Теперь он там не нужен и только размножает секрет по строкам:

```sql
update public.salon_secrets
   set whatsapp_cloud_app_secret = null,
       wa_connection_kind = 'platform'
 where whatsapp_cloud_waba_id is not null
   and whatsapp_cloud_app_secret is not null;
```

## 2. Создать НОВУЮ конфигурацию Embedded Signup (v4)

**Срок: до 15 октября 2026.** Meta отключает Embedded Signup v2 и v3 в этот день. Старый
`config_id` продолжает открывать старый поток и умрёт вместе с ним, а вместе с ним сломается
coexistence: номер салона уедет в облако целиком, и WhatsApp Business на телефоне владелицы
перестанет работать.

В кабинете приложения (`developers.facebook.com/apps/<APP_ID>`):

1. **Facebook Login for Business → Configurations → Create configuration.**
2. Тип — **Embedded Signup**, продукт — **WhatsApp Business Platform**.
3. Разрешения: `whatsapp_business_messaging`, `whatsapp_business_management` (оба уже одобрены).
4. Сохранить и **скопировать новый Configuration ID**.

Проверить поток можно в **Embedded Signup Builder** там же.

## 3. Переменные окружения

Ставятся в Cloudflare Workers (Settings → Variables) и в локальный `.env`.

### Обязательные для подключения WhatsApp

| Переменная                 | Что это                                                                                 | Где взять                                                 |
| -------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `VITE_META_APP_ID`         | ID приложения Qabyl. **Клиентская** — попадает в бандл, это нормально, App ID не секрет | `developers.facebook.com` → приложение → Settings → Basic |
| `VITE_WA_ES_CONFIG_ID`     | **НОВЫЙ** Configuration ID из пункта 2. Не старый                                       | там же → Facebook Login for Business → Configurations     |
| `META_APP_ID`              | То же значение, серверное. Участвует в обмене кода на токен                             | —                                                         |
| `META_APP_SECRET`          | Секрет приложения. **Никогда не в `VITE_`**                                             | Settings → Basic → App Secret → Show                      |
| `WA_PLATFORM_VERIFY_TOKEN` | Произвольная строка. Ею Meta подтверждает адрес вебхука                                 | придумать; вписать в Meta и сюда одинаково                |
| `PUBLIC_APP_URL`           | `https://qabyl.com`                                                                     | —                                                         |

### Уже должны быть (проверить, что не потерялись)

`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `VITE_SUPABASE_URL`,
`VITE_SUPABASE_PUBLISHABLE_KEY`, `GEMINI_API_KEY`, `CRON_SECRET`,
`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`.

### Необязательные

| Переменная                | Зачем                                                            |
| ------------------------- | ---------------------------------------------------------------- |
| `WA_CLOUD_API_VERSION`    | Версия Graph API. По умолчанию `v25.0` — менять только осознанно |
| `VITE_META_GRAPH_VERSION` | Версия для FB SDK в браузере. По умолчанию `v25.0`               |

> **Проверка:** если `VITE_META_APP_ID` или `VITE_WA_ES_CONFIG_ID` не заданы, кнопка «Подключить
> WhatsApp» честно скажет «подключение не настроено на стороне платформы» и не откроет пустое
> окно Meta. Захардкоженных значений по умолчанию в коде больше нет — раньше там стоял конкретный
> App ID, и салон в чужой сборке подключался бы к чужому приложению.

## 4. Вебхук приложения

`developers.facebook.com` → приложение → **WhatsApp → Configuration → Webhook**:

- **Callback URL:** `https://qabyl.com/api/public/wacloud`
- **Verify token:** значение `WA_PLATFORM_VERIFY_TOKEN`
- **Подписаться на поля:**
  - `messages` — сообщения клиентов (без него ассистент не услышит ничего)
  - `smb_message_echoes` — ответы владельца с телефона; по ним ассистент замолкает
  - `message_template_status_update` — результат модерации текстов уведомлений
  - `account_update` — бан и ограничения аккаунта салона
  - `history` и `smb_app_state_sync` — синхронизация переписки при coexistence

Последние четыре — новые. `message_template_status_update` и `account_update` теперь
обрабатываются кодом; без подписки на них статус текстов будет обновляться только по кнопке
«Проверить».

## 5. Перевести приложение в Live

**Без этого Embedded Signup не работает для чужих бизнесов.** Сейчас приложение
`Unpublished`: разрешения видны только разработчикам и тестировщикам самого приложения, и
владелец салона в окне ES не увидит ничего, что можно подтвердить.

`developers.facebook.com` → приложение → **Publish** → перевести в Live.

## 6. Access Verification (не срочно, но упирается быстро)

Сейчас лимит онбординга — **10 новых бизнес-клиентов в скользящие 7 дней**. Он поднимается до
200 только после **Business Verification + App Review + Access Verification**. Первые два есть,
третьего нет.

Пока не пройдено — планировать не больше 10 подключений в неделю.

## 7. Расписание проверки здоровья подключений

Новая cron-задача `wa-health` раз в час опрашивает Meta по каждому подключённому салону и пишет
владельцу в колокольчик, когда доступ отозван или аккаунт ограничен.

Отдельного действия не требует — она лежит миграцией
`supabase/migrations/20260909100000_wa_health_cron.sql` и применяется вместе с остальными
(`name: wa_health_cron`). Проверить после наката:

```sql
select jobname, schedule, active from cron.job where jobname = 'wa-health';
```

## 8. Что салон делает сам, а что нет

Это не наш чеклист, а то, о чём предупреждать клиента:

| Шаг                                      | Кто делает                  |
| ---------------------------------------- | --------------------------- |
| Регистрация, салон, услуги, мастера      | салон, сам, 5 минут         |
| Подключение WhatsApp                     | салон, сам, одна кнопка     |
| Тексты уведомлений и подписка на вебхуки | Qabyl, автоматически        |
| **Способ оплаты в Meta**                 | **салон, сам, обязательно** |
| Приглашение сотрудников                  | салон, сам                  |

**Про оплату говорить заранее.** Мы Tech Provider, а не Solution Partner: своей кредитной линией
салон не покрываем. Пока к WhatsApp Business Account салона не привязана карта, Meta не выпустит
ни одного сообщения. С 1 октября 2026 тарификация идёт по сообщениям (для KG ≈ $0.0077 за
сервисное), и платит их салон напрямую Meta. Экран подключения показывает это состояние
отдельным сообщением с кнопкой в биллинг Meta.

## 9. Проверка после всех шагов

1. Зарегистрировать новый аккаунт на `qabyl.com/auth` (с почтой, которой ещё не было).
2. Пройти мастер: название → сфера → город → услуги → мастер → WhatsApp.
3. На шаге WhatsApp нажать «Подключить», пройти окно Meta до конца.
4. Убедиться, что на вкладке WhatsApp написано «WhatsApp подключён» и тексты уведомлений
   перешли из «на проверке» в «работает» (обычно несколько минут).
5. Написать салону с другого телефона — ассистент должен ответить.
6. Записаться через ассистента и проверить, что запись появилась в календаре, а клиенту пришло
   подтверждение.

Пункт 4 — единственный, который занимает время: модерацию текстов делает Meta.
