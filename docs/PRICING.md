# Тарифы Qabyl: юнит-экономика и правила

Дата: 2026-09-13. Рынок: салоны красоты, Бишкек. Все цифры хранятся в базе (`billing_plans`,
`billing_settings`) и меняются без выкладки кода. Лимиты этой редакции — миграция
`20260913120000_trial_cap_and_business_default`.

## 3. Маржа

Расчёт `billing-logic.ts → estimateCost`. Всё в WhatsApp (самый дорогой канал).

|                                       | Start           | Business        | Pro             |
| ------------------------------------- | --------------- | --------------- | --------------- |
| **Реальный салон (~1 000 сообщений)** | **3 194 (71%)** | **5 134 (79%)** | —               |
| **Полный лимит**: себестоимость       | 2 225           | 4 125           | 7 925           |
| маржа                                 | **2 274 (51%)** | **2 374 (37%)** | **2 574 (25%)** |
| **60% лимита**: себестоимость         | 1 489           | 2 653           | 4 981           |
| маржа                                 | **3 010 (67%)** | **3 846 (59%)** | **5 518 (53%)** |
| Цена сообщения для салона на лимите   | 2,25 сома       | **1,62 сома**   | 1,31 сома       |

Худший случай ограничен: на полном лимите любой тариф остаётся в плюсе, а сверх лимита салон
докупает пакеты с маржой 54–69%. Прежний безлимит Pro уходил в убыток после ~10 800 сообщений.

**Пробный период** стоит Qabyl не больше 1 000 × 0,92 ≈ **920 сом** на салон, даже если он не
заплатит.

**Пакеты сообщений** (себестоимость 500 сообщений ≈ 460 сом): Start 69%, Business 61%, Pro 54%.

### Какой тариф выгоднее Qabyl

- **Business** — главный: самая высокая маржа в сомах у массового клиента и запас для загруженного
  салона. Новый салон начинает пробный период именно на нём.
- **Pro** — для сетей и салонов от ~5 700 сообщений.
- **Start** — вход для небольшого салона и переход на Business.

### Почему клиент переходит выше

- **Start → Business.** Вдвое больше сообщений, до 3 филиалов, аналитика, предоплата и возврат
  клиентов — за 2 000 сом. Start с одним пакетом (4 499 + 1 490 = 5 989 сом за 2 500 сообщений)
  почти равен Business (6 499 за 4 000).
- **Business → Pro.** От ~5 700 сообщений Business с пакетами дороже Pro, плюс филиалы до 10 и
  персональный менеджер.

## 4. Что происходит при превышении лимита

| Расход                          | Что видит салон                 | Что происходит                                                                                             |
| ------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 80%                             | уведомление «Израсходовано 80%» | всё работает                                                                                               |
| 100%, автодокупка **включена**  | —                               | списывается пакет, ассистент продолжает                                                                    |
| 100%, автодокупка **выключена** | «Сообщения закончились»         | ассистент замолкает; сообщения клиентов видны в переписках и на телефоне; подтверждения и напоминания идут |
| 110%                            | —                               | останавливаются и уведомления                                                                              |

Автодокупка по умолчанию включена: ассистент, замолкший посреди пятничного вечера, стоит салону
больше, чем пакет.

## 5. Оплата, отсрочка, блокировка

1. **Пробный период** начинается при создании салона: Business, 14 дней, 1 000 сообщений. В мастере
   подключения можно выбрать Start (30 дней) или Pro (7 дней) — срок считается от регистрации.
2. За 3 дня до конца пробного — напоминание об оплате.
3. **Оплата картой** через Freedom Pay. Карта запоминается, дальше продление списывается само
   каждый месяц в день оплаты. **Пока шлюз не подключён** — оплата переводом: владелец платформы
   открывает `/admin/billing?salon=<id>` и нажимает «Отметить оплату тарифа». Текст «Как оплатить»
   для салонов — `billing_settings.config.manual_payment_instructions`. Оплата вперёд не съедает
   пробные дни: месяц включается в день окончания пробного периода.
4. **Списание не прошло** → повтор через 1 день, потом через 2. Статус «нужна оплата», **3 дня
   отсрочки**: всё работает, висит предупреждение.
5. **Отсрочка кончилась** → **кабинет блокируется**: вход только на экран оплаты, новые записи не
   создаются ни через сайт, ни через ассистента, ни вручную. На странице записи салона клиенты
   видят, что запись временно недоступна. Данные не удаляются.
6. **Оплатили** → всё работает сразу.
7. **Повышение тарифа** — сразу, с доплатой за остаток месяца. **Понижение** — со следующего
   месяца.
8. **Отказ** — доступ до конца оплаченного месяца, дальше как блокировка.

Существующие пилотные салоны освобождены от оплаты (`billing_exempt`) и не блокируются.

## 6. Как менять цены и лимиты

Всё — SQL в Supabase, без выкладки.

```sql
-- поднять цену Business
update billing_plans set price_kgs = 6999 where code = 'business';

-- увеличить лимит сообщений на Start
update billing_plans set limits = jsonb_set(limits, '{messages_month}', '2500') where code = 'start';

-- Meta подняла тариф или изменился курс
update billing_settings set config = config || '{"wa_message_usd": 0.0085, "usd_kgs": 88.1}';

-- длиннее отсрочка
update billing_settings set config = config || '{"grace_days": 5}';

-- освободить салон от оплаты
update salon_subscriptions set billing_exempt = true where salon_id = '<id>';
```

Новая цена применяется к следующему списанию. Тариф пробного периода по умолчанию задан в триггере
`billing_on_salon_created` — меняется миграцией.
