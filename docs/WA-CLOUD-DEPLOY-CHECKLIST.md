## Шаг 1. Meta: подключить номер (делается заранее, ничего не ломает)

Выбран режим **coexistence** — номер продолжает работать в приложении WhatsApp Business, история
синхронизируется, а ваши ответы с телефона глушат ИИ.

1. [ ] **Business Manager → верификация бизнеса.** Без неё не одобрят шаблоны. Это самый долгий
       пункт (дни), поэтому он первый. Всё остальное работает и без него — кроме сообщений вне
       окна 24 часов, которые пока уходят через Green-API.
2. [ ] Создать приложение Meta (тип Business) → добавить продукт **WhatsApp**.
3. [ ] Подключить номер через **Embedded Signup для пользователей WhatsApp Business app**
       (именно этот путь даёт coexistence; обычная регистрация номера выключит его в приложении).
4. [ ] Записать **Phone Number ID** (это идентификатор, не сам номер) и **WABA ID**.
5. [ ] Создать постоянный токен системного пользователя с правом
       `whatsapp_business_messaging`. Временный токен на 24 часа не подойдёт.
6. [ ] Скопировать **App Secret**: Meta App → Settings → Basic.

Подписку на вебхуки настроим в шаге 5 — сначала должен существовать URL.

## Шаг 2. Применить миграцию к проду — ПЕРВОЙ

⚠️ **Строго до деплоя кода.** Функция `send-whatsapp` после обновления читает
`salons.wa_provider` и `wa_cloud_templates_ready`. Если этих колонок в базе нет, PostgREST
роняет **весь** запрос — и подтверждения записи перестанут отправляться **у всех салонов**, а не
только у переезжающих.

```bash
supabase db push --project-ref bfxexnpyfslfuelfkhzr
```

Проверить, что легло:

```bash
supabase migration list --project-ref bfxexnpyfslfuelfkhzr
```

- [ ] В списке появилась `20260815130000`
- [ ] Проверить, что дефолты не тронули существующие салоны:

```sql
SELECT wa_provider, count(*) FROM salons GROUP BY 1;
```
Ожидается: **все салоны `green_api`**. Если хоть один `cloud` — остановиться и разобраться.

## Шаг 5. Заполнить настройки и подписать вебхук

Всё на **тестовом салоне**, не на живом.

1. [ ] Админка → салон → **WhatsApp** → блок Cloud API. Вставить Phone Number ID, Access Token,
       App Secret, WABA ID → **Сохранить**.
2. [ ] Нажать **«Проверить подключение»**. Должно показать ваш номер и качество. Если ошибка —
       чинить здесь, дальше не идти.
3. [ ] Скопировать оттуда же **Callback URL** и **Verify Token**.
4. [ ] Meta App → WhatsApp → Configuration → Webhook: вставить оба значения, нажать Verify.
5. [ ] Подписаться на поля:
   - [ ] `messages` — сообщения клиентов (обязательно)
   - [ ] `smb_message_echoes` — **обязательно при coexistence**: по нему ассистент понимает, что
         вы ответили клиенту с телефона, и замолкает. Без подписки ИИ будет говорить поверх вас.

Переключатель провайдера пока **не трогать**.

## Шаг 6. Тест на тестовом номере

Салон всё ещё на Green-API — сейчас включаем Cloud API переключателем в блоке Cloud API.

- [ ] Щёлкнуть переключатель. Салон переехал; Green-API остался как путь отката.

Сценарии (писать с личного телефона на тестовый номер салона):

| # | Что сделать | Что должно быть |
|---|---|---|
| 1 | «Здравствуйте» | Ответ ассистента, синие галочки, «печатает…» |
| 2 | Записаться на услугу целиком | Запись появилась в календаре |
| 3 | Отправить фото | Ассистент видит фото (не «пришлите ещё раз») |
| 4 | Голосовое сообщение | Расшифровано и отвечено |
| 5 | Три коротких сообщения подряд | **Один** связный ответ, не три |
| 6 | **Ответить клиенту с телефона салона** | ИИ замолкает на 5 минут; в панели чатов ваш ответ виден как «Администратор» |
| 7 | Ответить клиенту **из панели чатов** | Дошло клиенту, ИИ замолк |
| 8 | Записаться через виджет на сайте (номер, который салону не писал) | Подтверждение пришло — **через Green-API**, потому что окно 24 ч не открыто |
| 9 | Дождаться напоминания за 2 часа | Пришло (через Green-API, пока шаблоны не одобрены) |

- [ ] Проверить `/admin/errors` — источник `wacloud-webhook` пуст или объясним
- [ ] Проверить блок «Диагностика» во вкладке — «Всё работает»

**Сценарий 6 — самый важный.** Если ИИ продолжает отвечать поверх вас, значит не подписано поле
`smb_message_echoes` (шаг 5.5).

## Откат

Занимает секунды и не требует деплоя:

1. Админка → салон → WhatsApp → **выключить переключатель Cloud API**.
2. Всё возвращается на Green-API. История диалогов, состояния и записи не теряются — диалог
   опознаётся по номеру телефона, а не по каналу.

Если сломалось что-то общее (а не один салон) — откатить деплой в Cloudflare на предыдущий.
Миграцию откатывать **не нужно**: новые колонки со значениями по умолчанию никого не трогают.
